# Auto Ticket Classification Using Flow Designer

# 📌 Project Overview

Auto Ticket Classification is a ServiceNow-based IT helpdesk automation project that automatically classifies support tickets using Flow Designer.

The user only needs to enter the Caller Name and Short Description of the issue. The system analyzes predefined keywords in the description and automatically assigns the appropriate Category and Subcategory.

# 🎯 Objectives

- Reduce manual effort in ticket classification.
- Improve consistency in assigning ticket categories.
- Minimize human errors.
- Automate the IT helpdesk ticket classification process.
- Provide a simple and maintainable no-code solution.

# ⚙️ How It Works

1. A student or staff member creates an IT support ticket.
2. The user enters the Caller Name and Short Description.
3. ServiceNow Flow Designer is triggered automatically.
4. The flow checks the description for predefined keywords.
5. The appropriate Category and Subcategory are assigned automatically.

# Example Classification

Keyword| Category| Subcategory
WiFi| Network| WiFi
Projector| Hardware| Projector
Password / Login| Access| Forgot Password
Slow / Hanging| Performance| Slow Computer

# 🛠️ Technologies Used
